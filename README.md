# BooksManageSystem（图书管理系统）
基于 C++ 开发的控制台版图书管理系统，支持图书信息的增删改查、借阅/归还管理、数据导入导出等核心功能，适配 Windows 平台编译运行。

## 项目简介
本项目是面向小型图书馆/书店的轻量级管理工具，通过控制台交互实现图书全生命周期管理，无需依赖数据库，数据存储于本地文本文件，操作简单、部署便捷，适合学习和小型场景使用。

## 技术栈 & 环境要求
### 开发环境
- 操作系统：Windows 10/11（x64）
- 编译工具：Visual Studio 2019/2022（支持 MSVC 编译器）
- 编程语言：C++（标准：C++11 及以上）
- 构建工具：MSBuild（VS 自带）

### 运行依赖
- 无需额外依赖，编译后生成可执行文件即可运行
- 需保证「测试数据.txt」与可执行文件同目录（数据存储文件）

## 快速开始
### 1. 克隆/下载项目
将项目代码克隆到本地，或直接下载压缩包解压：
```bash
git clone <你的仓库地址>
cd BooksManageSystem
```

### 2. 编译项目
#### 方式1：Visual Studio 打开编译
1. 双击 `BooksManageSystem.sln` 打开解决方案；
2. 选择「Debug | x64」编译配置（或 Release）；
3. 点击「生成」→「生成解决方案」（快捷键：F7）；
4. 编译产物输出到 `x64/Debug/BooksManageSystem.exe`。

#### 方式2：命令行编译（需配置 VS 环境变量）
```bash
# 调用 MSBuild 编译
MSBuild BooksManageSystem.sln /p:Configuration=Debug /p:Platform=x64
```

### 3. 运行项目
1. 进入编译产物目录：`cd x64/Debug`；
2. 双击 `BooksManageSystem.exe` 启动程序，或命令行运行：
```bash
BooksManageSystem.exe
```
3. 按照控制台提示输入指令，完成图书管理操作。

```

```

## 核心功能
1. **图书信息管理**
   - 新增图书：录入图书编号、名称、作者、出版社、库存等信息；
   - 修改图书：编辑已有图书的库存、作者等信息；
   - 删除图书：根据图书编号删除指定记录；
   - 查询图书：支持按编号、名称、作者模糊查询。
2. **借阅/归还管理**
   - 图书借阅：记录借阅人、借阅时间，扣减对应图书库存；
   - 图书归还：记录归还时间，恢复图书库存，支持逾期提醒。
3. **数据管理**
   - 数据导入：从「测试数据.txt」加载图书信息；
   - 数据导出：将当前图书数据保存到文本文件，支持备份。
4. **控制台交互**
   - 清晰的菜单指令（数字选择），支持循环操作，退出确认。

## 数据格式说明
「测试数据.txt」采用文本格式存储图书信息，每行一条记录，字段用分隔符（如逗号）分隔，示例：
```
图书编号,图书名称,作者,出版社,库存,是否可借
B001,C++ Primer,李普曼,人民邮电出版社,5,是
B002,算法导论,托马斯·科尔曼,机械工业出版社,3,是
```

## 常见问题
1. **编译报错「找不到头文件」**
   - 检查 `FUNCTION.h` 是否与 `Function.cpp`、`main.cpp` 同目录；
   - 确认 VS 项目配置中「包含目录」已覆盖当前目录。
2. **运行后数据未保存**
   - 确保「测试数据.txt」与可执行文件同目录，且有读写权限；
   - 退出程序前执行「数据导出」操作，避免数据丢失。
3. **控制台乱码**
   - 在 `main.cpp` 开头添加编码设置：
     ```cpp
     #include <windows.h>
     int main() {
         SetConsoleOutputCP(CP_UTF8); // 设置控制台编码为UTF-8
         // 其他逻辑...
     }
     ```
